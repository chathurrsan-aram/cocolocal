# M0 — Analysis of existing Coco Local motion (26 Sep 2026)

Sources reviewed (contact sheets in reference-sheets/, 4 fps):
- Coco Local — Basket Logo Reveal — 5s Square.mp4 (1080×1080, 60 fps, 5 s, has audio) — Chat's favourite
- Outro-Landscape-Logo-Only / Outro-Landscape-Tagline (1280×720, 30 fps, 5 s, silent)
- Outro-Vertical-Logo-Only / Outro-Vertical-Tagline (720×1280, 30 fps, 5 s, silent)
(The four outros share one system; the Tagline versions add the rule + "A little more local.")

## Basket Logo Reveal (5 s) — the base
Timeline: 0–0.5 grey dot darkens to navy on cream → 0.75–1.0 dot stretches into a navy rounded pill (the container) → 1.25–1.75 basket draws (handles, then rim, then body/slots) → 2.0–2.25 basket slides left → 2.5–3.5 wordmark appears letter by letter → 3.5–5.0 hold.
Works: true "one shape, never cut" (dot → pill → lockup card); stroke-draw of the basket is the brand's strongest move; calm, confident pacing; long hold.
Weak: letters fade in with a grey/half-opacity stage that reads muddy at 2.5–3.25 s; the pill on cream looks like a UI button (great for UI-morph pieces, less so as a full-frame ident); no tagline.

## Outros (5 s)
Timeline: 0–0.5 full-frame colour wipes (sky blue → peach → navy) with the basket riding across → 0.5–1.0 basket settles, a ring of dots bursts out → 1.0–1.25 wordmark reveals behind a clip → 1.5 peach rule draws → 1.75–2.0 tagline "A little more local." → 2–5 hold; a thin peach progress bar runs along the bottom.
Works: the colour-wipe opener (energetic, on-brand palette); peach rule + tagline gives a proper end card; long hold.
Weak: dot-ring particle burst (template look; banned by the code-motion-design skill); wordmark clipped mid-word ("co", "coco loca") looks glitchy; vertical lockup runs nearly edge to edge (~95% width, crowded); the progress bar distracts from the lockup; 720p / 30 fps only.

## Signature moves adopted for the kit
1. Dot → navy container → lockup (one shape, never cut) — from the Basket Reveal.
2. Basket stroke-draw in order: handles → rim → body → slots — from the Basket Reveal.
3. Basket slides left to make room; wordmark rises per letter, fully opaque (no grey mid-state), clipped from below.
4. Peach rule draws from centre, then tagline "A little more local." rises — from the Outros.
5. Full-frame colour wipes sky → peach → navy — ONLY as openers/cut points (sting, transitions), never behind the lockup.
6. Peach baseline bar — optional static brand element, never an animated progress bar.

Dropped: dot-ring particle bursts; glows; mid-word clipping; edge-to-edge vertical lockups; animated progress bar.
Note: there is no "sign light-up" in these files, so the kit keeps the skill's no-glow rule with no exception.
